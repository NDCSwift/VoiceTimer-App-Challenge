# 🎙️ Voice Timer App Challenge

A SwiftUI timer app built entirely using voice commands — a fun coding challenge.

## 📖 What this is
This project is a voice-controlled coding challenge where the entire app was built using only voice input. It demonstrates a working timer app in SwiftUI while showcasing an unconventional development workflow. A unique look at accessibility tools and voice-driven coding in action.

## ✅ Why you'd use it
- **Voice-coded experiment** — see what's possible when you build an app hands-free
- **Timer app implementation** — a clean SwiftUI timer you can learn from or extend
- **Coding challenge inspiration** — great starting point for your own voice or constraint-based challenges

## 🚀 Getting Started
1. Clone the repo
2. Open `VoiceTimer.xcodeproj` in Xcode
3. Select your target device or simulator
4. Update the bundle ID if needed
5. Build and run

## 📝 Notes
- Built with SwiftUI
- Requires Xcode 14+

## ⚙️ Requirements

- Xcode 14+
